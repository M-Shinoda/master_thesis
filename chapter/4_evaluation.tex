\chapter{評価}

本章では，第3章で提案・実装した災害分析基盤を約9ヶ月間（2025年2月中旬〜10月）運用し，その有効性を検証した結果を述べる．
まず運用実績とシステムの安定性を示し，次に収集データの統計的特性を分析する．
最後に，地震発生時のコメント反応や感情分析結果を通じて，YouTubeライブ配信コメントがSNSデータソースとして有効であるかを検証する．

\section{考察}

\subsection{YouTubeライブコメントの有効性}

約9ヶ月間の運用と分析を通じて，以下の点でYouTubeライブ配信コメントが災害時のSNSデータソースとして有効であることが示された．

\begin{itemize}
    \item \textbf{持続的な収集可能性}: 無償API枠内で長期運用が可能であり，Xの制約を補完できる
    \item \textbf{災害時の瞬間的反応の捕捉}: 地震発生後15分以内の感情変化を明確に観測可能
    \item \textbf{低コストなインフラ}: サーバレス環境とIaCにより，月額XX円程度で運用可能
\end{itemize}

\subsection{Xとの比較における差異}

\begin{itemize}
    \item \textbf{利点}: 大量収集が可能，視聴者という限定集団の同期的反応が明確
    \item \textbf{制約}: 拡散指標がない，過去データの遡及が不可，短文傾向が強い
\end{itemize}
